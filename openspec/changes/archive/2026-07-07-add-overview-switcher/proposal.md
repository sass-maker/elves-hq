# Add Overview Switcher

## Why

The task-room pane has the right surfaces, but too many of them are visible at once: Needs Me, Elf FM, Task Backlog, and Daily Brief stack before the room deck. The cockpit should keep those surfaces available without making the default view feel crowded.

## What Changes

- Add a compact overview switcher to the task-room pane.
- Show exactly one overview panel at a time: Needs Me, Elf FM, Backlog, or Brief.
- Keep each existing panel's behavior and actions.
- Show counts in the switcher so hidden panels still communicate their state.

## Out Of Scope

- Removing any existing panel.
- New persistence for panel choice.
- New daemon endpoints.
- Full redesign of the room pane.
