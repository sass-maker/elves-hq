# Add Focused Room Mode

## Why

The selected room has an expand button, but it currently does nothing. V0 task rooms should let the founder open a room and help an elf without the fleet sidebar and room list competing for attention. Focused room mode makes a task room feel like a real room instead of only a third pane.

## What Changes

- Make the selected room expand/collapse control functional.
- In focused mode, hide the fleet sidebar and task-room list and let the selected room occupy the cockpit.
- Provide an obvious back/collapse control that returns to the three-pane cockpit without losing selected room or tab state.
- Keep all room actions, asks, workbench tabs, previews, and notes available in focused mode.

## Out Of Scope

- Browser routing/deep links for focused rooms.
- Multiple room windows.
- Persisting focused mode across reloads.
